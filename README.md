# Home Credit Risk Prediction Project

## Project Overview
The Home Credit Risk Prediction project aims to analyze customer financial information and identify potential loan default risks.

## Objectives
- Analyze customer loan applications.
- Understand customer repayment behavior.
- Identify factors affecting loan default.
- Build an interactive risk analysis dashboard.
- Develop a machine learning prediction model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Machine Learning

## Dataset
Home Credit Default Risk Dataset

Source:
https://www.kaggle.com/competitions/home-credit-default-risk/data
